# 生き残るために

AIが生成するさまざまな極限状況を、プレイヤー自身の言葉で切り抜けていく、1ページ完結型のノベルゲーム風サバイバルミニアプリ。

## 公開URL

https://survive-for.pages.dev

## アプリ概要

「生き残るために」をテーマにした、AI生成型の極限状況ゲームです。

プレイヤーは、災害、ゾンビ世界、異世界、宇宙船事故、深海基地、ネット炎上、遅刻寸前の通学路など、ランダムに生成されるさまざまなシチュエーションに放り込まれます。

各ターンでは、AIが現在の状況・行動結果・次の選択肢を生成します。
プレイヤーは提示された選択肢を選ぶことも、自分で自由に行動を入力することもできます。

最大7ターンの中でどれだけ目的達成に近づけるかによって、最後のエンディングが変化します。

## 主な特徴

- AIが毎回異なる極限状況を生成
- プレイヤーの自由入力にAIが反応
- シリアスな状況に、ふざけた選択肢が混ざるノベルゲーム風UI
- 内部的な進行度によって、クリア・代償つき生還・曖昧な結末・バッドエンドが分岐
- エンディングはそれまでの行動履歴をもとに生成
- スマホでも遊びやすい1ページ構成

## Geminiを使った理由

このアプリでは、極限状況の導入文、ターンごとの行動結果、選択肢、エンディング文の生成にGemini APIを使用しています。

Geminiを選んだ理由は以下です。

- 日本語の文章生成が自然
- APIの利用コストが比較的安い
- Cloudflare Pages Functions からfetchで扱いやすい
- 短いゲーム文やJSON形式の生成に向いている
- ミニアプリとして試作するうえで、速度とコストのバランスが良い

## エンディングだけ別モデルにしている理由

通常の状況生成やターン処理では、コストと速度を優先して軽量なGeminiモデルを使用しています。

一方で、エンディングはゲーム体験の締めになる重要な部分です。
単なる結果報告ではなく、これまでの行動が反映された「ミニ小説のラスト」のような文章にしたかったため、エンディング生成だけ文章品質を優先したモデルを使用しています。

通常ターンではテンポを重視し、エンディングでは読後感を重視する構成にしています。

## 開発メモ

このアプリは、短期間で完成させることを重視したミニアプリです。

バックエンドサーバーを別途用意せず、Cloudflare Pages Functions 上でGemini APIを呼び出しています。
フロントエンドはシンプルなHTML/CSS/JavaScriptで構成し、1ページでゲーム開始からエンディングまで完結するようにしています。
